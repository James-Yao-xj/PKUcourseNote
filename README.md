## 第三学期整理入口

[总目录](Semester3/main.typ) · [课件与笔记对应表](Semester3/课件对应表.typ)

各课程目录中的 `main.typ` 为合订入口，单讲文件保留独立编译方式。新增与修订沿用原课程的 Typst 样式。

从 `CourseNote` 目录编译时，以该目录为资源根，例如：

```sh
typst compile --root . Semester3/ICS/main.typ /tmp/ICS-notes.pdf
```
